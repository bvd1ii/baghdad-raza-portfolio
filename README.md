# Baghdad Raza — Personal Portfolio

A responsive, multi-page student portfolio built strictly with plain HTML, CSS and JavaScript.

## Pages

- Home
- About and technical skills
- Academic projects with interactive detail panels
- Contact form using `mailto:`

## Features

- Fully responsive layout
- Dark and light themes with saved preference
- Mobile navigation
- Accessible keyboard interaction
- Scroll-reveal micro-animations
- No frameworks, libraries or external assets

## Run locally

Open `index.html` in a browser, or run a simple local server from this folder.

## Deployment

Import this repository into Vercel and deploy with the default static-site settings. No build command is required.
